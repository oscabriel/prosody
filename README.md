# Prosody

One self-hosted app for ebooks and audiobooks: request a book, fetch it, shelve it, sync the audio to the text, and read or listen with one position per book.

Pairing and alignment are built: a catalogue of the library, each book's text and audio aligned by the press and checked by ear, shown on one page. Reading comes next.
