# Prosody

One self-hosted app for ebooks and audiobooks: request a book, fetch it, shelve it, sync the audio to the text, and read or listen with one position per book.

The foundation is built: a catalogue of the library, kept by the model and shown on one page. Syncing and reading come next.

- Spikes and their results: `spikes/*/NOTES.md`
- Rules for agents working here: `AGENTS.md`
