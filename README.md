# Prosody

One self-hosted app for ebooks and audiobooks: request a book, fetch it, shelve it, sync the audio to the text, and read or listen with one position per book.

The reading room is built: a catalogue of the library, each book's text and audio aligned by the press and checked by ear, and a reading room where the audio follows the text and your place follows you between devices. Serving it without a dev server comes next.
