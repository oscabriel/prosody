# A work is known by its id, never by its title

A `WorkId` is `w-` and lower-case letters or digits, so it can name a folder or a cache as it is, and nothing is ever found or named by a title. A work the press finds takes its id from a hash of its shelfmark, so every walk gives the same folder the same id. A work you want takes a random id made by the device that asks, before anything is known about it.
