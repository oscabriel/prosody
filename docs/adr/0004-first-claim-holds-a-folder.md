# The first work to claim a folder holds it

Two works can reach for one `Author/Title` folder: a book wanted twice, or an audiobook grabbed for an ebook already shelved. `ShelfmarkClaim`, keyed by the shelfmark, gives the folder to the first claim and tells every later one whose it is. The later edition is then shelved for the first work, so the two pair, and no `Title (2)` folder is ever made.
