# A place is a sentence, and the later place wins

A sentence, as `<section path>#<span id>`, is the one locator for both text and audio, so a place is a sentence; a work with its audio alone keeps a time instead, and a work of pages a page. A place kept later replaces an earlier one and an older one is refused as `StalePlace`, so a phone that was offline cannot drag you back. Which device kept a place is the Session's to say, never the sender's.
