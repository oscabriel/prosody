# The press reports facts on every walk, and the model records what is news

The press's commands report what it found or did (`RecordAlignment`, `RecordCopy`, `RecordShelved`, `RecordProgress`), so they never reject: a fact that changes nothing records nothing. The press sends every work, edition, pair and edition alone again on every walk, and how each download stands every minute. Policies act only on new events, so repeating the facts is what lets a rule added later reach what was already in the library.
