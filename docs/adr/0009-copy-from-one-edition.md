# A work with no pair is copied from one edition, and a missed folder never downgrades a copy

A work without both text and audio gets a reading copy of one edition: its text if it has one, since a text is marked sentence by sentence, else its pages, else its audio. Before asking the press, the `ReadingCopy` policy checks what the work has by now, because a share that drops a folder for one walk makes a pair look like an edition alone. The same file at the same size is never copied twice; a file of another size under the same name is copied again.
