# Every search and every try is numbered, and the first answer wins

A search for a want, an alignment and a copy each run as a numbered try, and the aggregate holds one at a time. An answer to a number that is no longer the latest records nothing, so a late answer can never overwrite a newer one. An alignment's deadline is a command on the same aggregate as the press's answer, scheduled before the press is asked, so the aggregate decides the race and a press that never answers is still caught.
