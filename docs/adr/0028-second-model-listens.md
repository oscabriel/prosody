# An alignment is not believed until a second model has listened

The aligner finishes cleanly even when it is wrong, so a second speech model of a different family, Whisper base.en, listens to 40 aligned sentences spread through the book, and the copy is refused unless three in four are heard right; good books scored 37 to 40 and a bad one 0. ffmpeg can also drop what it cannot decode and exit cleanly, as it did with xHE-AAC, so the decoded length of every file is checked against the length its container states.
