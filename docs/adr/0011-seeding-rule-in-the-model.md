# The seeding rule is a constant of the model

`OBLIGATION` (72 hours within 30 days) lives in the model, not in a setting, so the model that refuses `ReleasePayload` and the desk that shows the hours owed can never disagree. The hours counted are the download client's own, which run on while a tracker credits none, so the desk asks you to check before you release. Releasing takes a payload out of the client's list and leaves its files.
