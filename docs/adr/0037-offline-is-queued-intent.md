# Offline is queued intent

Your place is kept on the device at once, with the id of the command that carries it, and sent whenever the model can be reached; it is sent again under the same id until the model answers, so a place that did arrive is never recorded twice. A room opens at the newer of the device's place and the model's, and waits three seconds for the model's word, because the model may be out of reach while the browser still thinks it is online. After a lost answer the app asks the server every five seconds until it answers.
