# The app is one open book, and the desk is a tool

The design is an open book of paper and ink: a leaf on the left that holds still and the page on the right. State is shown by a mark, the manicule, never by a hue; labels are true small caps; at night the five colour tokens trade places and nothing else changes. The desk is a tool, so it keeps the same tokens with a sans face and no leaf.
